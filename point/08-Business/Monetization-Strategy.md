# Monetization Strategy

> **Status:** Active (Tint Economy 기반으로 재설계)
> **Last Updated:** 2026-04-27
> **Economy Design:** [[2026-03-27-pointint-economy-design]]

## 수익화 철학

강한 무료 제작 경험으로 유저를 데려오고, AI 보정/생성과 프리미엄 출력에 쓰는 Tint로 첫 수익을 만든다. 이후 공식 콘텐츠와 마켓플레이스 실험으로 생태계 수익을 확장한다. 월 구독은 사용하지 않는다.

## 수익원 4개

| # | 수익원 | 도입 시점 | 과금 방식 |
|---|---|---|---|
| 1 | **Tint 팩 판매** | Phase 3 | 일회성 팩 구매 (₩4,900~₩39,900) |
| 2 | **AI 보정 / 프리미엄 출력** | Phase 3~ | Tint 소모 (자동 보정 500T, HiDPI 1,000T, AI 생성 1,500T 가정) |
| 3 | **공식 콘텐츠 판매** | Phase 5 | 개별 판매 (테마팩 ₩2,000~9,900) |
| 4 | **마켓 수수료 실험** | Phase 5 | 20% 정책 초안, Creator Beta에서 검증 |

## 경제 순환 구조

```
[실제 돈] → Tint 구매 → [유저 지갑]
                            │
              ┌─────────────┼─────────────┐
              ▼             ▼             ▼
          AI 사용        마켓 구매      콘텐츠 구매
          (소멸)           │          (Pointint 수익)
                     ┌─────┴─────┐
                  판매자 80%   수수료 20%
                  (이전)       (소각)
                     │
                 [판매자 지갑] → AI/콘텐츠에 재소비 → 더 좋은 창작 → 다시 판매
```

## Phase별 수익 로드맵

| Phase | 수익 요소 | 역할 |
|---|---|---|
| **1-2** | 없음 | 무료 도구로 유저 확보. 제작→다운로드 흐름 검증 |
| **2.5** | 없음 / 테마팩 기반 준비 | 폴더 아이콘, 배경화면, theme-pack draft로 장기 유료 상품 기반 검증 |
| **3** | Tint 팩 판매 | 첫 수익. 업로드 이미지 자동 보정과 HiDPI 내보내기 = Tint 소모. 출석 적립 시작 |
| **4** | Tint 소모처 확대 | AI 커서 생성 추가. 생성 1회 1,500T 가정, 기본 보정 포함 |
| **5** | 공식 콘텐츠 + 마켓 실험 | 공식 테마팩 판매와 Creator Beta 검증. 마켓은 확정 수익 모델이 아니라 실험으로 시작 |

## 전환 트리거

| 전환 | 트리거 | 핵심 질문 |
|---|---|---|
| Guest → Member | 저장/17종 욕구 | "이 커서를 잃고 싶지 않다" |
| Member → Tint 구매 | 보정/HiDPI/AI 생성 욕구 | "무료로 맛봤는데 더 깔끔하게 만들고 싶다" |
| 구매 → 반복 구매 | Tint 소진 | "또 만들고 싶다" |
| Member → Creator Beta | 판매 의사 + 품질 기준 충족 | "내가 만든 걸 팔고 싶다" |

## Tint 소스 / 싱크 균형

### 소스 (유입)

| 소스 | 양 | 성격 |
|---|---|---|
| Tint 팩 구매 | 주요 유입 | 실제 매출 |
| 일일 출석 | +50/일 | 재방문 미끼 |
| 커서 제작 완료 (일 1회) | +50/일 | 제작 활동 유도 |
| 활동 보상 | 소량 | 참여 유도 |
| 친구 초대 | 일회성 보너스 | 바이럴 |

### 싱크 (소멸)

| 싱크 | 양 | 성격 |
|---|---|---|
| 커서용 자동 보정 | 500 Tint/회 (확정) | 업로드 이미지 품질 개선 |
| HiDPI 내보내기 | 1,000 Tint/회 (확정) | 프리미엄 출력 |
| AI 커서 생성 | 1,500 Tint/회 가정 | Phase 4 검증, 기본 보정 포함 |
| 공식 콘텐츠 구매 | 수천~수만 Tint | 감정적 가치 |
| 마켓 수수료 | 거래의 20% 정책 초안 | Phase 5 Creator Beta에서 검증 |
| 마켓 등록비 | 소량 검토 | 스팸 방지 + 소각 |

**건강한 경제:** 싱크 ≥ 소스 → Tint 가치 유지

무료 Tint는 업로드 이미지 자동 보정과 HiDPI 내보내기 맛보기에 쓸 수 있다. AI 커서 생성은 신규 Member 체험 1회 또는 제한된 trial credit만 제공하고, 반복 생성은 구매 Tint 중심으로 둔다.

## 가격 원칙

- Guest는 약하면 안 된다 — 무료 제작 경험이 hook
- 17종 제작과 17종 자동 변형은 Member 무료 핵심 가치다 — Pointint의 차별점을 결제 뒤로 숨기지 않는다
- 기본 ZIP/설치 안내/restore flow는 무료 신뢰 장치다 — 설치 가능성을 유료로 막지 않는다
- 첫 결제는 부담 없어야 한다 — Starter ₩4,900
- 너무 싸면 품질 의심 — Etsy 17종 ₩13,000~19,000 앵커 참고
- 사용자에게는 Tint보다 결과 중심 이름을 먼저 보여준다 — "커서용 자동 보정 1회", "AI 커서 생성 1회", "HiDPI 내보내기"
- AI 생성 가격은 Phase 4에서 모델 비용 기반으로 재검증하되, 현재 가정 가격은 1,500 Tint
- 올리기는 쉽지만 내리기는 어렵다 — 보수적으로 시작
- 장기 핵심 상품은 테마팩이다
- 마켓플레이스는 Phase 5 실험이다 — 현금 정산과 Creator 운영 정책은 이때 재검토
