# Tier & Pricing

> **Status:** Active (Tint Economy 기반으로 재설계)
> **Last Updated:** 2026-04-27
> **Economy Design:** [[2026-03-27-pointint-economy-design]]

## 통화: Tint

Pointint의 단일 내부 통화. 월 구독 없음. Tint 팩을 구매하거나 활동으로 적립한다.

## 티어 구조

| 상태 | 비용 | 권한 |
|---|---|---|
| **Guest** | 무료, 비회원 | 업로드 제작 (.cur/.ani), 배경 제거 (기본), 편집, Hotspot, 시뮬레이션, 3종 다운로드 |
| **Member** | 무료, 가입 | Guest 전부 + 프로젝트 저장, 17종 전체 제작, 17종 자동 변형, 기본 ZIP/설치 안내/restore flow, 일일 Tint +50 (출석) + +50 (제작 시), 갤러리 참여 |
| **Creator Beta** | 신청/승인형 (Phase 5~) | Member 전부 + 마켓 판매 실험, 크리에이터 프로필 |

## 과금 원칙

Pointint의 기본 약속은 **제작과 기본 다운로드는 무료, AI 보정과 프리미엄 출력은 Tint**다. 17종 제작, 17종 자동 변형, 기본 ZIP/설치 안내/restore flow는 유료 장벽이 아니라 제품 신뢰와 회원 전환 장치로 둔다.

| 기능 | Guest | Member | Tint 필요량 |
|---|---|---|---|
| 업로드 제작 + 3종 다운로드 | O | O | 무료 |
| 기본 ZIP / 설치 안내 / restore flow | O (3종 기준) | O (17종 기준) | 무료 |
| 17종 전체 수동 제작 | X | O | 무료 |
| 17종 자동 변형 (규칙 기반) | X | O | 무료 |
| 프로젝트 저장 / 재수정 | X | O | 무료 |
| 커서용 자동 보정 | X | O | 500 Tint (Phase 3~) |
| HiDPI 멀티사이즈 (64/128px) | X | O | 1,000 Tint (확정) |
| AI 커서 생성 | X | O | 1,500 Tint 가정 (Phase 4 검증) |
| 마켓 구매 | X | O | Phase 5 실험, 구매 Tint 중심 |
| 마켓 판매 | X | Creator Beta만 | Phase 5 정책 재검토 |

### 유료 기능 표시 원칙

사용자에게는 Tint보다 먼저 결과 중심 이름을 보여준다.

| 사용자 표시 | 내부 과금 |
|---|---|
| 커서용 자동 보정 1회 | 500 Tint |
| HiDPI 내보내기 | 1,000 Tint |
| AI 커서 생성 1회 | 1,500 Tint 가정 |

커서용 자동 보정은 배경 잔여물 정리, 가장자리 보정, 자동 크롭, 커서 크기 기준 선명도 보정, 여백/중심 조정을 하나로 묶은 기능이다. AI 커서 생성 1회에는 커서용 자동 보정 1회를 기본 포함한다.

## 전환 퍼널

```
Guest ──→ Member ──→ Tint 구매자 ──→ Creator Beta
 (제작)    (저장/17종)  (보정/생성/HiDPI)  (신청/승인)
```

| 전환 | 트리거 | 마찰도 |
|---|---|---|
| Guest → Member | 만든 커서를 저장하고 싶다 / 17종 전체 만들고 싶다 | 낮음 (무료 가입) |
| Member → Tint 구매 | 무료 Tint로 보정/HiDPI를 맛본 후 더 쓰고 싶다 / AI 생성을 반복하고 싶다 | 중간 (₩4,900 첫 결제) |
| Member → Creator Beta | 판매 의사 + 품질 기준 충족 | 중간 (신청/승인) |

## 재방문 보상 (무료 Tint)

| 장치 | Tint | 주당 최대 |
|---|---|---|
| 일일 출석 | +50/일 | 350 |
| 커서 제작 완료 (일 1회) | +50/일 | 350 |
| 갤러리 공유 | +200 (주 2회 한정) | 400 |
| 주간 챌린지 | +500 | 500 |
| **합계** | | **~2,300/주** |

무료 Tint는 업로드 이미지 보정과 HiDPI 내보내기 맛보기에 사용한다. AI 커서 생성은 신규 Member 체험 1회 또는 제한된 trial credit만 제공하고, 반복 생성은 구매 Tint 중심으로 둔다.

## 마켓플레이스 실험 정책

Marketplace는 Phase 5 전까지 확정 수익 모델이 아니라 실험 모델로 둔다.

| 항목 | 정책 |
|---|---|
| Creator 진입 | 자동 승급이 아니라 신청/승인형 Beta |
| 판매 수수료 | 20% 정책 초안 |
| 등록비 | 소량 Tint 검토 (스팸 방지) |
| 거래 통화 | 초기 Tint 기반 검토 |
| 현금 정산 | Phase 5에서 재검토 |

## 경계의 원칙

- **제작과 기본 다운로드는 제한하지 않는다.** Guest도 무제한 제작 가능.
- **17종 제작과 17종 자동 변형은 Member 무료 핵심 가치다.** 결제 장벽이 아니라 가입 전환 장치로 둔다.
- **AI 보정, AI 생성, 프리미엄 출력만 Tint로 게이팅한다.** 기본 결과물을 쓸 수 없게 만들지 않는다.
- **설치 가능한 기본 패키징은 무료 신뢰 장치다.** 기본 ZIP/설치 안내/restore flow는 유료로 막지 않는다.
- **AI 생성에는 기본 보정을 포함한다.** 생성 후 다시 보정 비용을 요구하는 이중 과금처럼 보이지 않게 한다.
- **마켓플레이스는 Phase 5 실험이다.** 초기 수익 핵심은 AI 생성, 업로드 이미지 보정, HiDPI, 공식 테마팩이다.
- **구독 없음.** 사용 빈도가 낮은 제품에 월 구독은 맞지 않는다.
- **올리기는 쉽지만 내리기는 어렵다.** 보수적으로 시작.
