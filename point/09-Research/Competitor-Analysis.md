# Competitor Analysis

> [!info]
> **Status:** Active<br>
> **Last Updated:** 2026-04-27<br>
> **Role:** 경쟁 사이트 재조사 후 빠르게 보는 요약본. 상세 근거와 해석은 [[Competitive-Landscape]]를 본다.

## Executive Summary

Pointint의 경쟁은 세 부류로 나뉜다.

1. **직접 경쟁:** Custom Cursor, Sweezy, ImageToCursor, Cursor.cc, RealWorld Cursor Editor, CursorFX
2. **콘텐츠/마켓 경쟁:** Cursors-4U, DeviantArt, VSThemes, Etsy cursor/theme sellers
3. **인접 취향 플랫폼:** Wallpaper Engine, Rainmeter, Lively, Desktop Mate

2026-04-27 재조사 기준 핵심 판단은 아래와 같다.

- **Custom Cursor가 가장 강한 직접 경쟁자다.** Chrome 확장만 600만 사용자, 61.6K 평점, 웹사이트의 Windows 앱, 커뮤니티, Creator 도구까지 보유한다.
- **Sweezy는 감성 커서 확장으로 빠르게 성장했다.** Chrome Web Store 기준 50만 사용자, 2.6K 평점, 4.8점을 보이며 Windows용 CUR/ANI 다운로드 가이드도 제공한다.
- **ImageToCursor 같은 단순 웹 변환기가 새 직접 비교군이다.** 이미지 업로드, 크기 선택, hotspot 지정, live preview, `.cur` 다운로드를 제공하지만 세트 제작, ANI, AI, 설치 패키징은 없다.
- **Cursor.cc와 RealWorld Cursor Editor는 오래된 DIY/파워툴 기준점이다.** Pointint가 더 쉬워야 할 이유와 결과물 품질 기준을 동시에 보여준다.
- **Etsy는 유료 수요 검증 신호다.** 커서팩과 데스크톱 테마팩이 이미 디지털 다운로드 상품으로 팔린다.
- **Wallpaper Engine과 Desktop Mate는 장기 확장 벤치마크다.** 커서 자체가 아니라 "데스크톱에 취향 오브젝트를 올리고 돈을 쓰는 행동"을 검증한다.

## Pointint Wedge

Pointint가 잡아야 할 포지션은 더 명확해졌다.

`내 이미지를 실제로 쓰는 Windows cursor set으로 바꾸는 가장 쉬운 웹 제작기`

이 포지션은 단순 변환기와 다르다.

- 단일 `.cur` 파일이 아니라 **Windows role set**을 만든다.
- "파일 변환"이 아니라 **source image -> cleanup -> hotspot -> role preview -> package** 흐름을 판다.
- 다운로드 후 알아서 적용하는 것이 아니라 **ZIP + INF + restore INF**로 적용 신뢰를 준다.
- 브라우저 커서가 아니라 **Windows 전체에서 쓰는 결과물**을 만든다.
- 장기적으로 cursor pack에서 **theme pack / desktop object / monitor interior**로 확장할 수 있다.

## Watchlist

- Custom Cursor가 Creator와 Windows 앱을 더 통합하면 Pointint의 직접 차별점이 좁아질 수 있다.
- Sweezy가 Windows role set을 2개에서 15개 이상으로 확장하면 감성 커서팩 경쟁이 강해진다.
- ImageToCursor류 SEO 페이지가 "png to cur", "image to cursor" 검색 의도를 선점할 수 있다.
- Etsy의 cursor/theme seller는 Pointint 마켓이 생길 경우 외부 경쟁자가 된다.
- Windows 11/12의 커서 적용 정책 변화는 설치 패키징과 restore flow에 직접 영향을 준다.
